# 🌐 CSS Position Lab Task

This project demonstrates how different **CSS position properties** — `static`, `relative`, `absolute`, `fixed`, and `sticky` — work in a webpage layout.

## 🧩 Features
- **Header** → uses `static` position  
- **Navigation Bar** → uses `fixed` position  
- **Hero Section** → image positioned `absolute`  
- **Content Box** → positioned `relative`  
- **Footer** → positioned `sticky`  

## 📄 Files Included
- `position.html` → Main HTML file demonstrating all CSS position types
